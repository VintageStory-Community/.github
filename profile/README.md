# 复古物语非官方社区愿景

- **[Vintage Story 模组中文库](https://mods.vintagestory.top/)**：全部由HansJack开发，依赖Discourse生态和SSO系统，实现账号通用，采用语义搜索解决中文无法搜索的难题。[Vintage Story 模组中文库项目仓库](https://github.com/VintageStory-Community/mods.vintagestory.top)
- **[Vintage Story 中文社区](https://vintagestory.top/)**：以Discourse系统构建玩家社区，社区采用默认主题和部分插件。
- **[MediaWiki插件 DiscourseAuth](https://github.com/VintageStory-Community/DiscourseAuth)**：DiscourseAuth 是一个 MediaWiki 扩展，用于将 Discourse SSO 登录接入 MediaWiki。
- **[Vintage Story Server Launcher](https://mods.vintagestory.at/vssl)**：复古物语服务器启动器，面向《Vintage Story》独立服的桌面启动与运维工具，核心目标是把版本下载、实例创建、配置维护、日志控制台、存档管理、模组管理、地图预览和 QQ 机器人联动集中到同一套界面里。
- **[VSMAP](https://github.com/VintageStory-Community/vsmap)**：独立地图生成项目，类似chunkmap网站，实现种子+世界生成JSON生成预览地图，仅完成地表地形。

---

- **[Vintage Story Mod Chinese Library](https://mods.vintagestory.top/)**: Fully developed by HansJack. It relies on the Discourse ecosystem and SSO system to enable unified accounts across platforms, and uses semantic search to solve the problem of Chinese keywords not being searchable. [Vintage Story Mod Chinese Library Project Repository](https://github.com/VintageStory-Community/mods.vintagestory.top)

- **[Vintage Story Chinese Community](https://vintagestory.top/)**: A player community built with the Discourse system, using the default theme and several plugins.

- **[MediaWiki Plugin DiscourseAuth](https://github.com/VintageStory-Community/DiscourseAuth)**: DiscourseAuth is a MediaWiki extension that integrates Discourse SSO login into MediaWiki.

- **[Vintage Story Server Launcher](https://mods.vintagestory.at/vssl)**: A desktop launch and management tool for *Vintage Story* dedicated servers. Its core goal is to integrate version downloading, instance creation, configuration maintenance, log console, world save management, mod management, map preview, and QQ bot integration into a single unified interface.

- **[VSMAP](https://github.com/VintageStory-Community/vsmap)**: An independent map generation project, similar to the chunkmap website. It generates preview maps from seed + world generation JSON, currently only supporting surface terrain.
